# 基于多设计模式下的同步&异步日志系统
## 项目目标
本项目要实现一个日志系统，支持多级别日志消息、同步和异步日志，支持可靠写入控制台、支持多线程并发写日志

## 开发环境
Ubutun vscode g++ Makefile

## 核心技术
类层次设计 C++11（多线程、智能指针、右值引用）

## 日志系统介绍

### 同步写日志
输出日志时，必须等待日志输出语句执行完毕后，才能执行后面的业务逻辑语句，日志输出语句与程序的业务逻辑语句在同一个线程运行，每次调用一次打印日志API就对应一次系统调用write写日志文件

在高并发场景下，若日志数量不断增加，大量的日志陷入等量的write系统调用，有一定的系统开销;同时打印日志的进程附带了大量同步的磁盘IO,影响程序性能。

### 异步写日志
异步写日志指的是日志输出语句与业务逻辑语句并不是在同一个线程中运行，而是有专门的线程用于进行日志输出操作，业务线程只需要将日志放到一个内存缓冲区中不用等待即可继续执行后续业务逻辑（作为生产者），而日志的落地操作交给单独的日志线程去完成（作为消费者）。

## 作用
1. 日志写入指定位置（标准输出，指定文件，滚动文件）日志系统需要支持将日志消息落地到不同的位置————多落地方向。<br>
2. 日志写入指定位置，支持同步和异步的方式。<br>
3. 日志输出以日志器为单位，支持多日志器（不同的项目组有不同的输出策略）。<br>

## 模块划分
1. 日志等级模块：将日志分为多少个等级，不同的日志有对应不同的等级，以便于控制输出。<br>
2. 日志消息模块：封装一条日志所需要的各种要素（时间，线程ID,文件名，行号，日志等级，消息主体）。<br>
3. 消息格式化模块：按照指定的格式，对日志消息关键要素进行组织，最终得到一个指定格式的字符串。<br>
4. 日志落地模块：负责对日志消息进行指定方向的写入输出。<br>
5. 日志器模块：对以上几个模块的整合，包括日志限制输出等级，消息格式化模块对象，日志落地模块对象、同步日志器模块、异步日志器模块。<br>
6. 异步线程模块：负责异步日志的实际落地输出功能。<br>
7. 单例日志器管理模块：对日志进行全局管理，以便于能够在项目的任何位置获取指定的日志器进行日志输出。<br>

### 日志等级模块
1. 定义日志系统所包含的所有日志等级，从低到高包括：
UNKNOWN=0,DEBUG 调试等级日志，INFO 提示等级日志，WARNING 警告等级日志，ERROR 错误等级的日志，FATAL 致命错误等级的日志，OFF 关闭日志。
项目中都会设置一个默认的日志输出等级，只有输出的日志等级大于等于默认的，才会进行输出。
2. 提供一个接口，将对应等级的枚举，转换成一个对应的字符串 DEBUG-> "DEBUG"

### 日志消息类
中间存储一条日志消息所需的各种要素，包括：
1. 日志的输出时间 
2. 日志等级 
3. 源文件名称 
4. 源代码行号
5. 线程id
6. 日志主体消息
7. 日志器名称
### 日志输出格式化
对日志消息进行格式化，组织成为指定格式的字符串。<br>
pattern成员：保存日志输出的格式化字符串,格式如下：<br>
> %d{%H:%M:%S}：表示日期时间，花括号中的内容表示日期时间的格式。<br>
> %T：表示制表符缩进。<br>
> %t：表示线程ID<br>
> %p：表示日志级别<br>
> %c：表示日志器名称，不同的开发组可以创建自己的日志器进行日志输出，小组之间互不影响。<br>
> %f：表示日志输出时的源代码文件名。<br>
> %l：表示日志输出时的源代码行号。<br>
> %m：表示给与的日志有效载荷数据<br>
> %n：表示换行<br>

FormatItem成员：格式化子项数组：不同的格式化子项，会从日志消息中取出指定的元素，转换为字符串。
包含以下成员：
> MsgFormatItem ：表示要从LogMsg中取出有效日志数据<br>
LevelFormatItem ：表示要从LogMsg中取出日志等级<br>
NameFormatItem ：表示要从LogMsg中取出日志器名称<br>
ThreadFormatItem ：表示要从LogMsg中取出线程ID<br>
TimeFormatItem ：表示要从LogMsg中取出时间戳并按照指定格式进行格式化<br>
CFileFormatItem ：表示要从LogMsg中取出源码所在文件名<br>
CLineFormatItem ：表示要从LogMsg中取出源码所在行号<br>
TabFormatItem ：表示一个制表符缩进<br>
NLineFormatItem ：表示一个换行<br>
> OtherFormatItem ：表示非格式化的原始字符串<br>
